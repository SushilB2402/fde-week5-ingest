# Data Quality Rules

These rules run in `quality.py` after Pydantic schema validation (`schema.py`) and ingestion (`pipeline.py`).

Design decision:
- **Flag, do not reject rows**: `quality.py` keeps every row in `data/out/loaded.csv` so ingestion reconciliation (`read == loaded + rejected`) stays intact and `PROBLEM.md` outcomes (`found-active`, `found-inactive`, `not-found`) remain visible.
- **Error** rules flag severe structural or data-integrity failures and set the overall quality status to `FAIL`.
- **Warning** rules flag anomalies or drift for review in `reports/quality_report.md` without failing the run on their own.

| ID | Rule | Group | Check (Plain Words) | Threshold | Severity | Action |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **QR-01** | Missing postcode on active practice | Nulls | `epraccur` rows marked `ACTIVE` should have a non-empty `postcode` (and overall `epraccur` postcode null rate stays low). | `0` missing postcodes on `ACTIVE` rows and `< 2%` null rate across `epraccur` postcodes | **Error** | Flag affected `epraccur` rows and log counts/samples in the quality report. |
| **QR-02** | Missing prescribing metrics or SNOMED rate | Nulls | `epd` rows must have `quantity` and `actual_cost` present; `snomed_code` missingness must not exceed `1%`. | `0` nulls for `quantity`/`actual_cost` (**Error**); `snomed_code` null rate `<= 1%` (**Warning**) | **Error** (metrics) / **Warning** (SNOMED rate) | Flag rows missing metrics as `error`; flag elevated `snomed_code` missingness (`> 1%`) as `warning`. |
| **QR-03** | Duplicate practice code in EPRACCUR | Duplicates | Each `practice_code` in `epraccur` should appear only once. | `0` duplicate `practice_code` rows in `epraccur` (`keep=False` flag count) | **Error** | Flag all rows sharing a duplicate `practice_code` in `epraccur` and report counts/samples. |
| **QR-04** | Duplicate practice registration record | Duplicates | Each `practice_code` in `registrations` should appear only once. | `0` duplicate `practice_code` rows in `registrations` (`keep=False` flag count) | **Error** | Flag all rows sharing a duplicate `practice_code` in `registrations` and report counts/samples. |
| **QR-05** | Patient list size range and outliers | Ranges | `registrations` `patient_count` must be positive (`> 0`); counts above `100,000` are flagged as high-volume outliers. | `patient_count > 0` (**Error**); `patient_count <= 100,000` (**Warning**) | **Error** (`<= 0`/null) / **Warning** (`> 100,000`) | Flag missing/non-positive counts as `error` and counts `> 100,000` as `warning` without dropping rows. |
| **QR-06** | Zero or negative quantity/cost on EPD | Ranges | `epd` rows should have positive `quantity` (`> 0`) and non-zero/non-negative `actual_cost` (`>= 0.01`). | `quantity > 0` and `actual_cost >= 0.01` (`0` rows below threshold) | **Warning** | Flag zero/low-cost or non-positive-quantity `epd` rows for review without dropping them. |
| **QR-07** | UK postcode format | Format | Populated `postcode` values should match standard UK postcode formatting, with at least `99.5%` valid. | `>= 99.5%` of non-null postcodes match UK format (`< 0.5%` malformed) | **Error** | Flag rows with malformed postcodes and report counts/samples. |
| **QR-08** | Practice code missing from EPRACCUR | Referential | `epd` and `registrations` `practice_code` values should exist in `epraccur` (`not-found` outcomes). | `0` non-EPRACCUR rows missing from `epraccur` (`100%` match preferred) | **Warning** | Flag `not-found` rows and report counts/samples in the quality report. |
| **QR-09** | Non-active practice reference | Consistency | `epd` and `registrations` rows referencing a practice in `epraccur` with status other than `ACTIVE` (`found-inactive`) must stay within `2%`. | `< 2%` of non-EPRACCUR rows linked to non-`ACTIVE` practices | **Warning** | Flag `found-inactive` rows and report counts/samples in the quality report. |
| **QR-10** | Source row volume within baseline bounds | Volume | Each source's row count should stay within `±15%` of its baseline count (`epd`: 63,839; `registrations`: 6,128; `epraccur`: 15,717). | Within `85%–115%` of baseline row count | **Warning** | Flag sources outside the `±15%` window in the quality report. |
